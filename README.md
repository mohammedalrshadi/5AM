# 5AM — Sports Facility Booking System

A sports facility booking system developed as a university project to help
students discover sports facilities, check availability, and manage bookings.

## Project Objectives

- Investigate the current sports facility booking process.
- Identify user needs and potential problems.
- Design a user-friendly booking system.
- Develop a functional application prototype.
- Apply Agile principles throughout development.

## Development Methodology

The team follows an Agile approach with three planned Sprints.

Each iteration involves planning, design, development, testing, and review.

**Project Management:** Trello  
**Version Control:** Git & GitHub

## Main Features

The following features are proposed and will be refined after requirements analysis:

- User authentication
- Sports facility listing
- Facility availability checking
- Booking management
- Booking cancellation
- Administrative management
